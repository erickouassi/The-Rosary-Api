# Privacy Policy for The Rosary API

**Effective Date:** October 2026

The Rosary API (`https://the-rosary-api.vercel.app`) provides daily Roman Catholic Rosary prayer data.

## 1. Data Collection
- **No Personal Data Collected:** The API does not require user accounts, logins, or registration.
- **Server Logs:** Standard web server logs (IP address, request headers, user-agent) may be temporarily processed by Vercel hosting infrastructure for security and telemetry purposes.
- **Cookies:** The API does not use cookies or tracking technologies.

## 2. Use of Data
Any log data collected automatically by the hosting provider is strictly used to maintain service availability, reliability, and security.

## 3. Third-Party Services
The API hosting infrastructure is provided by [Vercel](https://vercel.com/legal/privacy).
